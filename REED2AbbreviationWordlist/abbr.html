Abbreviations from REED Collections

This is a dictionary wordlist generated from Records of Early English Drama (REED) data as TEI XML and JSON for display in a dataTable. You can sort and filter by each column or generally overall. The source for this is available at: https://github.com/jamescummings/REED/tree/master/REED2AbbreviationWordlist and is licensed CC+By.

There are 11735 distinct forms from 51628 abbreviated word instances across 5 languages found in 10 collections.

If you want to filter the attestation column for an expanded word containing certain non-contiguous letters separate them by a space, e.g. 'a p i' and it should find them in any order.
